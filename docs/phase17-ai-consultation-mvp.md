# Phase 17 AI Consultation MVP

## 2026-05-11 농약 후보 정리 변경

- 농약 후보 정리는 상담 답변 생성 컨텍스트가 아니라 자료/상담 탭의 보조 자료 조회 기능으로 유지한다.
- PSIS 목록 결과가 많은 경우 Gemini는 공식 등록정보 그룹 안에서 대표 3~5개만 선택한다.
- 선택 결과는 농약 처방이나 우선순위가 아니라 `공식 등록정보를 초보자가 비교하기 쉽게 줄인 후보`로 표시한다.
- 작용기작 원문 코드는 전면 UI에서 강조하지 않고, 제품 라벨과 전문가 확인 대상으로 남긴다.

## 목표

- `자료/상담`을 나열식 리포트 화면이 아니라, 현재 선택 필지 정보를 알고 답변하는 AI 상담 화면으로 운영한다.
- AI 상담 자체는 기존 Supabase 데이터와 `gemini-proxy`를 사용한다.
- 농약등록정보 검색은 상담 답변 생성 컨텍스트가 아니라 보조 탭의 공식 자료 조회 기능으로 분리한다.

## 화면 구조

- 기본 탭: `AI 상담`
- 보조 탭: `농약 안전/등록정보`
  - `병해충명을 알아요`: 작물명, 병해충명/적용대상, 농약명으로 PSIS 등록정보를 조회한다.
  - `공식 사진에서 고르기`: 작물명 기준 NCPMS 공식 사진 후보를 보여주고 사용자가 선택한 후보명으로 PSIS 등록정보를 조회한다.
  - PSIS에 선택한 병해충명/적용대상과 정확히 일치하는 등록정보가 0건이면, 같은 작물에서 부분 명칭으로 확인되는 PSIS 등록 적용대상 후보를 별도로 표시한다. 이 후보는 원래 병해충에 대한 자동 대체 처방이 아니라 사용자가 다시 조회할 수 있는 공식 등록대상 목록이다.
  - `내 사진으로 찾기`: 사진 판독 화면으로 이동해 NCPMS 후보 비교를 먼저 수행한다.
- 상단: 선택 필지 상태 요약
- 본문 좌측: 상담 기록 목록
  - 각 상담 기록은 직접 삭제할 수 있다.
- 본문 중앙: 선택 상담의 메시지 목록과 질문 입력
  - 질문 입력창에서 `Enter`는 전송, `Shift+Enter`는 줄바꿈으로 동작한다.
- 본문 우측: AI가 참고한 필지 컨텍스트 요약

## 저장 구조

- `consultation_threads`
  - `id`, `field_id`, `title`, `created_at`, `updated_at`, `expires_at`
  - 상담 목록은 `updated_at DESC` 기준 최근순으로 표시한다.
  - 새 채팅 버튼을 누르면 새 thread를 만든다.
  - 사용자가 질문을 보내면 해당 thread의 `updated_at`과 `expires_at`을 갱신한다.
  - 사용자가 상담 기록을 삭제하면 해당 thread를 삭제한다.
- `consultation_messages`
  - `id`, `field_id`, `thread_id`, `role`, `content`, `context_snapshot`, `created_at`
  - 메시지는 선택된 `thread_id` 기준으로 조회한다.
  - 기존 필드 단위 메시지는 마이그레이션에서 `기존 상담 기록` thread로 연결한다.
  - thread 삭제 시 외래키 cascade로 함께 삭제된다.
- RLS
  - thread와 message 모두 `public.is_field_owner(field_id)` 기준으로 접근을 제한한다.
  - message insert는 `thread_id`가 같은 `field_id`에 속하는지 함께 확인한다.
- 보관 기간
  - 상담 데이터는 마지막 활동 기준 30일 후 삭제 대상이 된다.
  - `purge_expired_consultation_threads()`가 만료 thread를 삭제하고, message는 cascade로 함께 삭제된다.
  - `pg_cron`이 가능한 환경에서는 매일 03:15에 정리 작업을 예약한다.

## AI 상담 컨텍스트

AI 답변 생성 시 매 질문마다 다음 데이터만 사실 근거로 전달한다.

- 선택 필지 정보: 작물, 생육 단계, 위치, 면적, 위험도
- 최근 7일 기상 요약: 평균/최고/최저 기온, 강수, 습도, 풍속
- 이번 주 농사 브리핑: 사용자가 `요약` 버튼으로 생성한 `weekly_farm_infos.summary_status=ready` 데이터
- 최근 사진 진단 기록: 후보명, 신뢰도, 부위, 체크리스트
- 작업 카드 상태: 미완료, 진행 중, 완료, 보류
- 선택 상담 thread의 최근 대화 일부

병해충 위험 후보명, 점수, 판단 이유, NCPMS 공식 근거명은 상담 AI 컨텍스트에서 제외한다.

## 답변 원칙

- 병해충 확정 진단 금지
- 농약 자동 처방 금지
- 희석배수, 사용량, 사용 횟수 임의 안내 금지
- 확실하지 않은 정보는 `확실한 정보 없음`으로 명시
- 농약 사용 관련 질문에는 PSIS 등록정보, 공식 안전사용지침, 제품 라벨, 전문가 상담 확인 안내
- 답변 형식은 `현재 판단`, `확인할 것`, `오늘 할 일`, `주의사항` 순서

## 범위 밖 작업

- 상담 AI가 PSIS 조회 결과를 근거 컨텍스트로 직접 받아 농약명을 추천하는 기능
- 물량/면적 입력 기반 희석량 계산기
- NCPMS 공식 사진 선택만으로 병해충을 확정하는 기능
- 필요 시 스트리밍 채팅 전환
