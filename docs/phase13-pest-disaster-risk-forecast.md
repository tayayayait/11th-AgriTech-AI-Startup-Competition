# Phase 13 Pest and Disaster Risk Forecast

## 목표

KMA 날씨, 필지 작물명, NCPMS 작물별 병해충 후보, 농작물 재해예방자료를 결합해 필지별 병해충 위험 예보를 생성한다.

이 작업은 사용자 요청 기준 Phase 5에 해당한다.

## 구현 범위

- `src/domain/pest/pestRiskForecast.ts`
  - KMA 날씨 조건 기반 병해충 위험 산식
  - 농사로 공식 자료 건수 반영
  - `진단` 표현을 사용하지 않는 예보/확인 권고 문구 생성
- `src/services/pestRiskForecastService.ts`
  - NCPMS 작물별 병/해충 후보 조회
  - KMA 위험 조건에 맞는 농작물 재해예방자료 조회
  - `pest_risks.reasons`, `pest_risks.official_sources` 저장
  - 필지 `risk_score`, `risk_level` 갱신
- `src/pages/Dashboard.tsx`
  - 선택 필지 기준 위험 예보 생성
  - 병해충 위험 원인 표시
  - 공식 근거자료 표시

## 산식

- 고습 + 적정 온도: 병 발생 가능성 확인 필요
- 강수: 강수 후 병해충 발생 가능성 확인 필요
- 강풍: 상처 부위와 2차 병해 확인 필요
- 고온/저온: 생육 스트레스 후 병해충 취약성 확인 필요
- NCPMS 작물별 병/해충 후보: 공식 참고 후보로 표시하되, 후보 개수만으로 위험 점수를 올리지 않음
- 농사로 재해예방자료: 고온, 저온, 강풍/태풍 등 KMA 조건과 연결되는 경우 반영

점수는 KMA 날씨 위험도, 날씨 기반 가산점, 농사로 병해충 발생정보/재해예방자료 가산점을 합산하되 최대 100점으로 제한한다.
NCPMS 통합검색 결과는 작물별 병해충 카탈로그 성격이므로 실제 위험 신호로 가산하지 않는다.

## 표현 원칙

- 사용하지 않는 표현: `진단`, `확정`, `처방`
- 사용하는 표현:
  - `병해충 위험 예보/확인 권고`
  - `확인 필요`
  - `공식 근거자료`

## 저장 구조

`pest_risks`에 다음 값을 저장한다.

- `field_id`
- `crop_name`
- `candidate_name`: 예보/확인 권고명
- `score`
- `reasons`: 위험 원인 배열
- `official_sources`: 농사로 공식 근거자료 배열

동일 필지, 동일 `candidate_name`, 동일 점수의 예보가 30분 안에 이미 저장되어 있으면 기존 예보를 재사용한다.
그 외에는 동일 필지와 동일 `candidate_name`의 기존 예보를 삭제 후 최신 결과를 저장한다.

## 검증 결과

2026년 5월 6일 대시보드 실검증:

- 필지: `벼`
- 오늘 위험도: `25 / 100`, `낮음`
- 위험 원인:
  - `기상 위험 신호가 낮습니다.`
  - `벼 병해충 위험 예보/확인 권고`
- `pest_risks` 저장 확인:
  - `candidate_name`: `벼 병해충 위험 예보/확인 권고`
  - `score`: `25`
  - `reasons`: `농사로 병해충 발생정보 4건 확인`
  - `official_sources`: 병해충 발생정보 제 1~4호 저장

## 한계

- 농사로 병해충 발생정보는 작물별 후보 산정에 사용하지 않고 최신 공통 참고자료로만 표시한다.
- 현재 결과는 위험 예보와 현장 확인 권고이며 사진 기반 병해충 판독이나 확정 진단이 아니다.
- 복숭아는 NCPMS 작물코드 `FT020604`로 매핑한다.
