## API 범위

팜맵 OpenAPI CSV/PDF에서 확인된 필지 조회 기능은 다음 범위다.

- PNU 기반 데이터 조회
- 좌표 기반 데이터 조회
- 중심좌표 + 반경 검색
- 읍면동리코드 + 농경지분류 조회
- 읍면동코드 + 갱신유형/갱신일자 조회
- 팜맵 + 국토정보기본도 중첩 조회
- 지적기반 경작면적 분석 조회

법정동코드 DOCX 기준 API는 다음 범위다.

- 서비스: `StanReginCd`
- 엔드포인트: `getStanReginCdList`
- 방식: REST GET
- 필수 파라미터: `ServiceKey`, `type`, `pageNo`, `numOfRows`, `flag`
- 선택 파라미터: `locatadd_nm`
- 주요 응답: `region_cd`, `locatadd_nm`, `sido_cd`, `sgg_cd`, `umd_cd`, `ri_cd`

법정동코드 API는 주소 문자열을 좌표로 변환하지 않는다. 따라서 도로명/장소 검색, 주소 자동완성, 주소 직접 좌표 변환 UI는 제거했다.

## 구현 범위

필지 등록 화면은 실제 가능한 API 흐름만 제공한다.

- 좌측 패널은 실제 팜맵 검색과 유사하게 `주소`, `지역` 2개 탭으로 구성한다.
- `주소`: `지번`, `PNU` 검색 방식만 제공한다.
- `주소 > 지번`: 법정동명 검색 후 상위 법정동 후보의 팜맵 필지를 `BJD + landCd(01~04)`로 조회해 PNU 기반 필지 주소 후보를 먼저 표시
- `주소 > 지번`: 팜맵 필지 후보가 없으면 법정동코드 선택, 본번/부번 입력, PNU 19자리 생성, 팜맵 PNU 조회 흐름으로 대체
- `주소 > PNU`: 사용자가 입력한 PNU 19자리로 팜맵 조회
- `지역`: `시도 -> 시군구 -> 읍면동 -> 리` 단계형 선택을 제공한다.
- `지역 > 분류`: 선택한 법정동코드와 농경지분류 코드로 `getFarmmapDataSeachBjdAndLandCode.do` 조회
- `지역 > 분류`: 리를 선택하지 않은 읍·면 검색은 하위 리 법정동코드를 순회 조회하고, 첫 필지 결과가 있으면 지도 중심을 해당 필지로 이동
- `지역 > 분류`: 선택 조건의 필지 결과가 0건이면 같은 법정동의 전체 분류 필지를 한 번 더 조회해 지도 이동용 대표 좌표만 사용한다. 이 후보는 필지 목록이나 등록 정보로 채우지 않는다.
- `지역 > 분류`: 같은 법정동의 전체 분류도 0건이면 제공 API 범위 안에서 이동 좌표를 만들 수 없으므로, 지도 이동 대신 명확한 안내 문구를 표시한다.
- `지역 > 분류`: 팜맵 API 실응답 기준 `getFarmmapDataSeachBjdAndLandCode.do`는 `apiVersion=v2`로 호출
- `지역 > 본번/부번`: 선택 지역 코드와 지번으로 PNU를 생성한 뒤 PNU 조회
- `지역 > 면적`: 면적 조건이 있으면 `getFarmmapDataSeachAnalysisBaseAttr.do`로 PNU 후보를 찾고, 해당 PNU를 다시 상세 조회
- 지도 클릭은 패널 탭이 아니라 팜맵 지도 클릭 이벤트로 유지한다.
- `분류`: `전체(논, 밭, 과수, 시설)`, `논`, `밭`, `과수`, `시설` 드롭다운 제공

분류 코드는 팜맵 농경지분류 기반 데이터 API에 맞춰 사용한다.

- 논: `01`
- 밭: `02`
- 과수: `03`
- 시설: `04`
- 전체: `01`, `02`, `03`, `04`

## 제거한 UI

다음은 제공 문서의 현재 API 범위만으로 구현할 수 없거나 화면에서 실제 동작하지 않던 항목이므로 제거했다.

- 도로명 검색 드롭다운
- 명칭/장소 검색 드롭다운
- 좌표 직접 입력 탭
- 미구현 지도 도구 버튼
- 미구현 레이어 전환 버튼
- 팜맵 홈페이지 메뉴처럼 보이지만 앱 내부 동작이 없는 상단 메뉴

## 현재 한계

2번째 참고 이미지의 `도로명` 주소 검색은 제공된 팜맵 OpenAPI와 법정동코드 API만으로 구현할 수 없다. 도로명주소 API 또는 VWorld 주소 검색 API가 별도로 필요하다.

3번째 참고 이미지의 `본번/부번`, `산`, `면적`, `분류` 조건은 같은 단일 API로 처리되는 구조가 아니다.

- `본번/부번`, `산`: PNU 생성 후 PNU 조회
- `분류`: `BJD + landCd` 조회
- `면적`: 지적기반경작면적분석 조건 조회 후 PNU 상세 조회

## 환경 변수

법정동코드 조회는 Supabase Edge Function `standard-region-proxy`를 통해 호출한다.

- `STANDARD_REGION_API_KEY`
- `STANDARD_REGION_BASE_URL=https://apis.data.go.kr/1741000/StanReginCd`

현재 `.env.example`에는 변수가 정의되어 있다. 실제 `.env` 또는 Supabase 함수 환경에는 `STANDARD_REGION_API_KEY`가 설정되어야 법정동 검색이 동작한다.
