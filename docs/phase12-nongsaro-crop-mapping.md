# Phase 12 Nongsaro Crop Mapping

## 목표

사용자가 입력한 작물명을 농사로 API가 실제로 반환하는 검색 단위로 변환한다.

이 작업은 사용자 요청 기준 Phase 4에 해당한다.

## 적용 범위

- 농작업일정: `farmWorkingPlanNew`
- 주간농사정보: `weekFarmInfo`
- 병해충발생정보: `dbyhsCccrrncInfo`

## 매핑 기준

- `벼` → 농작업일정 그룹 `논농사`
- `배추`, `고추`, `마늘`, `양파`, `딸기`, `토마토` → 농작업일정 그룹 `채소`
- `감자`, `고구마`, `콩`, `옥수수` → 농작업일정 그룹 `밭농사`
- `사과`, `배`, `포도` → 농작업일정 그룹 `과수`
- `인삼` → 농작업일정 그룹 `약초`
- `버섯` → 농작업일정 그룹 `버섯`

주요 작물 15개 이상은 `src/domain/nongsaro/cropMapping.ts`에 명시 매핑한다.

## Fallback 규칙

### 농작업일정

1. 작물명 직접 매칭
2. 작물명 매핑 그룹 매칭
3. 매칭 그룹의 `kidofcomdtySeCode`로 일정 목록 조회

### 주간농사정보

1. 작물명/관련 키워드 제목 검색
2. 검색 결과가 없으면 최신 목록 조회
3. 최신 목록에서 관련 키워드가 제목에 있으면 우선 반환
4. 관련 항목도 없으면 최신 주간농사정보를 반환
5. PDF 요약 결과가 선택 작물 직접 근거 없음(`relevant=false`)이면 주간농사정보를 작물 권고로 승격하지 않는다.
6. 이 경우 별도 `AI 참고` 섹션을 표시하고, Gemini 내부 농업 지식 기반으로 참고 브리핑을 생성한다.

AI 참고 브리핑은 모든 작물명에 동일하게 적용한다. 특정 작물명을 하드코딩하지 않고 사용자가 선택한 작물명, 필지 생육단계, 기상 맥락을 프롬프트에 전달한다.

AI 참고 브리핑 표시 제한:

- `주간농사정보 직접 근거 없음`을 명시한다.
- `공식 주간농사정보 근거 없음 · AI 내부 지식 기반`을 명시한다.
- 기준일의 월/계절과 제공된 기상 맥락에 따른 일반 점검으로만 표현한다.
- 최신 예찰, 지역별 발생, 품종별 세부 기준처럼 실시간 확인이 필요한 내용은 확정하지 않는다.
- 농약명, 희석배수, 수확 전 사용일수, 제품명, 확정 병해충 판단은 생성하지 않는다.
- 근거가 부족하면 `확실한 정보 없음`으로 표현한다.

### 병해충발생정보

1. 최신 연도 선택
2. 작물명/관련 키워드 제목 검색
3. 검색 결과가 없으면 최신 목록 조회
4. 최신 목록에서 관련 키워드가 제목에 있으면 우선 반환
5. 관련 항목도 없으면 최신 병해충발생정보를 반환

## 검증 결과

실 API 기준 2026년 5월 6일 확인:

- 농작업일정: 12개 작물 모두 그룹 기반 조회 성공
- 주간농사정보: 12개 작물 모두 최신 목록 fallback으로 조회 성공
- 병해충발생정보: 12개 작물 모두 최신 목록 fallback으로 조회 성공

확인 작물:

- 배추
- 고추
- 마늘
- 양파
- 감자
- 콩
- 사과
- 배
- 포도
- 딸기
- 토마토

농사로 현재 응답 특성:

- `weekFarmInfoList`의 `subject` 검색은 위 주요 작물/그룹 키워드 대부분에서 0건이다.
- `dbyhsCccrrncInfoList`의 제목 검색도 작물명 기준으로는 0건이다.
- 따라서 주간농사정보와 병해충발생정보는 최신 목록 fallback이 필수다.
